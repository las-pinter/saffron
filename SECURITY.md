# Security policy

Saffron stores personal financial data, so security reports are welcome.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository. Do not open a public
issue for a security problem.

Include the affected version or commit, steps to reproduce, and the impact you
expect. You can expect a first answer within 7 days.

## Supported versions

Saffron is in early development. Only the latest release on `main` receives
fixes.

## Deployment guidance

Saffron is designed to run on a private network, for example behind Tailscale
or another VPN. Do not expose it directly to the public internet.
